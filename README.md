# Active-Directory-Home-Lab
this is my virtual AD environment for testing group policies, security configurations, and domain administration scenarios
(just the beginning! more to come!)

## Quick Facts
- Setup: Windows Server 2025 | Domain: night.corp
- VMs: 1 DC, client machines
- Tools: PowerShell, Qemu/KVM
- Purpose: Learning/testing/development

## What's Included
- Powershell Automation
- Example GPO configurations
- Security hardening templates
- Troubleshooting guides
